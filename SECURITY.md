# Security Policy

## Supported versions

Only the default branch is supported for security fixes.

## Reporting a vulnerability

Do not open a public GitHub issue for a suspected vulnerability.

Use GitHub's private vulnerability reporting flow from the repository **Security** tab. If that option is unavailable, contact the repository owner privately through GitHub with:

- a short description of the issue;
- reproduction steps or a proof of concept;
- the potential impact;
- any suggested mitigation.

Please do not include credentials, tokens, or personal data in a public issue or pull request.

## Response

Reports will be reviewed as soon as practical. A fix may be published through a private fix branch and a coordinated release or pull request.
